# 滿月臺 — 고려 개경 만월대 3D 복원

1123년, 송나라 사신 서긍(徐兢)이 개경에 한 달 남짓 머물며 『선화봉사고려도경』에 적어 남긴 고려의 정궁 **본궐(本闕)**을
웹 브라우저에서 둘러볼 수 있게 다시 세운 3D 복원입니다. 2007–2018년 남북 공동발굴 보고서, 『고려도경』·『고려사』의 기록,
현존 고려 목조건축의 비례를 함께 써서 송악산 남쪽 기슭의 축대 41곳, 전각과 문 45채, 회랑·담장·성벽, 물길과 숲을 만들었습니다.

## 실행하기

빌드 과정이 없는 ES 모듈 프로젝트입니다. three.js(0.170.0)는 `cdn.jsdelivr.net` 에서 불러오므로 인터넷 연결이 필요합니다.

```bash
node tools/serve.mjs          # → http://localhost:5173
```

ES 모듈은 `file://` 로 열리지 않으니 꼭 위처럼 http 서버로 여세요(Node 18 이상, 따로 설치할 것은 없습니다).

**한 파일 배포본**: `node tools/build.mjs` 를 돌리면 CSS·JS 를 모두 품은 `dist/index.html` 이 만들어집니다(`esbuild` 필요: `npm install`).
이 파일 하나만 아무 정적 서버에 올리면 됩니다. 예: `python3 -m http.server -d dist 8080` → <http://localhost:8080>.

권장 환경은 WebGL2 가 되는 최신 데스크톱 브라우저입니다. 휴대폰에서는 자동으로 ‘보통’ 화질(그림자 2048, 숲 밀도 55 %)로 시작합니다.

## 조작

| 동작 | 마우스·키보드 | 터치 |
|---|---|---|
| 돌려 보기 | 왼쪽 단추로 끌기 · 방향키 | 한 손가락으로 끌기 |
| 옮기기 | 오른쪽 단추 · Shift+끌기 · Shift+방향키 | 두 손가락으로 끌기 |
| 가까이·멀리 | 휠 (커서 쪽으로 다가감) · `+` `−` · `PgUp` `PgDn` | 두 손가락 벌리기·오므리기 |
| 정보 보기 | 전각·회랑·담장·이름표 누르기 | 누르기 |
| 걷기 | `G`, 걷는 중 `W A S D`·방향키, `PgUp` `PgDn` 위아래, `Shift` 달리기, `Esc` 나가기 | 왼쪽 아래 조이스틱, 화면 끌어 둘러보기 |
| 시간대 | `1` `2` `3` `4` | 아래 도구 막대 |
| 안내 여행 | `T`, 이전·다음 `←` `→` | 도구 막대 ‘안내’ |
| 평면도로 가기 | 평면도에 초점을 두고 방향키로 표적, `Enter` | 평면도 누르기 |
| 이름표 · 유적 · 평면도 · 역사 · 도움말 | `L` · `R` · `M` · `I` · `H` | 도구 막대 (휴대폰 세로: 이름표·도움말·화질은 ‘더보기’) |

한 글자 단축키는 ‘도움말’에서 끌 수 있습니다(방향키·`Esc` 는 그대로).

휴대폰 세로 화면(폭 720 px 이하)의 도구 막대에는 자주 쓰는 여섯 가지(시간대·유적·걷기·안내·평면도·역사)와 **‘더보기’** 만 두어,
360 px 폭에서도 단추마다 46×48 px 넘게 누를 자리가 있습니다(390 px 50×48, 430 px 56×48, 가로 844×390 은 아홉 단추 모두 48×44).
‘더보기’ 메뉴(이름표·조작 도움말·화질)는 스크린리더에 메뉴로 읽히고, 위아래 방향키·`Home`·`End` 로 옮겨 `Enter` 로 고르며
`Esc`·`Tab` 으로 닫으면 초점이 ‘더보기’ 단추로 돌아옵니다.

## 기능

- **안내 여행 12곳** — 하늘에서 본 궁궐, 승평문, 구정과 신봉문, 창합문, 33단 대계단, 회경전 뜰, 축대 위 전망, 장화전, 원덕전,
  건덕전과 서부 건축군, 경령전, 송악산 자락. 해설은 모두 사료와 발굴 성과에 근거하며, 자동 재생도 됩니다.
  넓은 화면에서는 왼쪽 해설 패널만큼, 휴대폰에서는 아래 패널만큼 화면 중심을 옮겨 보는 대상이 가리지 않게 했습니다
  (안내 여행을 여는 동안 오른쪽 아래 평면도는 잠시 접힙니다). 평면도·정보 카드·목록·휠·끌기로 직접 움직이면 자동 재생은 멈춥니다.
- **정보 카드** — 전각·문·회랑·담장·다리·지점을 누르면 칸 수와 평면(기둥 중심) 크기, 뒤에 바뀐 이름, 설명, 고증 메모와 함께
  **신뢰도(확실·추정·불확실)** 를 보여 줍니다(부분마다 다르면 ‘칸수: 확실 · 치수: 추정’처럼). ‘가까이 가기’로 그 자리까지 날아갑니다.
- **이름표** — 1·2등급 전각, 지점, 주변 산 이름(휴대폰에서는 1등급 전각·산·지금 보는 곳만). 지형·건물·회랑·담장에 가리면 사라지고,
  겹치면 덜 중요한 것(안내 여행 지점의 대상은 먼저)을, 패널·도구 막대·평면도 밑에 들어가는 것은 숨깁니다. 위치·이름이 추정·가설인 곳은 ‘?’ 를 붙입니다.
- **복원 / 유적 보기** — ‘유적’을 켜면 목조 건물과 담장을 모두 걷어 내고, 1361년 홍건적에 불탄 뒤 오늘까지 남은 축대·계단·초석만
  풀밭 위에 보여 줍니다. 궁성·도성 성벽은 풀 덮인 낮은 둔덕으로 바뀝니다.
- **시간대 4가지** — 팔관회 아침(음력 11월 보름 무렵, 남동쪽의 낮은 겨울 해), 한낮(하지), 해 질 녘(가을),
  **보름달 밤**(남동쪽 하늘에 뜬 만월과 달무리, 별). 해의 방위·고도는 개경의 위도와 궁궐 중심축의 방위(진북에서 서쪽으로 17°)로 계산합니다.
  처마 밑 공포·첨차의 황단(黃丹) 밑면은 뜰에서 튀어 오른 빛을 반구광에 비례해 조금 더 받아, 그늘 속에서도 붉은 밤색이 아니라 주황으로 읽힙니다
  (반구광이 어두운 해 질 녘·달밤에는 거의 더하지 않아 스스로 빛나 보이지 않음).
- **걷기** — 사람 눈높이(1.6 m)로 마당과 계단을 걸어 다닙니다. 기단·담장은 막히고, 높은 축대에서는 뛰어내리지 않습니다.
  하늘에서 걷기를 켜면 보던 곳에서 가장 가까운 마당에 내려섭니다.
- **평면도(미니맵)** — 궁성 평면 위에 지금 보는 곳과 해·달 방향을 표시하고, 누르면 그곳으로 날아갑니다.
- **다른 학설로 바꿔 보기** — ‘역사 › 복원에 대하여’에서 학설이 갈리는 네 가지를 바로 바꿔 볼 수 있습니다:
  회경전 뜰 바닥(박석 ↔ 전돌), 공포(주심포 ↔ 다포), 단청(12세기 적색 주조 ↔ 14세기 상록하단), 금원 정자 기와(회흑색 ↔ 청자기와).
- **역사와 고증** — 연표, 장소 목록, 참고 자료 65건, 복원 원칙과 가장 불확실한 부분.
- **화질** — 높음·보통·낮음(그림자 해상도, 숲 밀도, 해상도 배율; 휴대폰 세로에서는 ‘더보기’ 안). 계속 그리는 동안 33 fps 아래로 느리면 해상도를, 그래도 느리면
  그림자 맵을 알아서 낮추고, 다시 빨라지면 되돌립니다. 창을 다른 배율의 화면으로 옮기면 해상도도 따라 맞춥니다.
  장면은 무언가 바뀔 때만 다시 그리고, 그림자 맵은 빛이 바뀌거나 보는 곳이 멀리 옮겨 갈 때(또는 전각 LOD 단계가 바뀔 때)만
  갱신합니다 — 제자리에서 돌려 보기만 해서는 다시 그리지 않습니다.

## 고증의 바탕과 불확실성

자세한 근거는 **[docs/research.md](docs/research.md)** 에 정리했습니다. 요점만 추리면:

- **기준 시점 1123년.** 가장 자세한 동시대 기록(『고려도경』)이 이때의 것이고, 드러난 서부 건축군 유구도 12–13세기 전성기의 배치입니다.
  이름은 1138년 개칭 이전의 것(회경전·건덕전·신봉문·창합문)을 쓰고 뒤의 이름을 함께 적었습니다.
- **확실한 것** — 회경전 정면 9칸(39.16 m)×측면 4칸, 높이 7.4 m·33단 대계단 4개소, 회경전 일곽 회랑의 규모, 창합문·회경전문의 칸 수,
  궁성 둘레 약 2,170 m, 장화전 축이 약 5° 틀어진 사실, 서부 건축군 건물터 40여 동.
- **추정한 것** — 목조 상부 구조 전체(기둥 높이, 공포, 지붕 물매, 단청)는 현존 고려 불전(부석사 무량수전 등)과 송 『영조법식』에서 추정했습니다.
  단청은 조선식 모로단청이 아니라 12세기 적색 주조로 칠했습니다. 서부 건축군의 대지 높이는 보고서 수치와 SRTM 표고 경향으로 짰습니다.
- **가장 불확실한 것** — 발굴되지 않은 승평문·구정·동락정의 위치와 규모, 궁 안 광명천 물길과 금교, 서부 건축군 전각 이름의 비정,
  궁성·황성의 선형. 금원 정자·좌춘궁·동지·만령전 등은 기록에 근거한 **가상 배치**입니다.
- 모든 전각·회랑·담장·다리·지점의 정보 카드에 신뢰도를 붙였고, 사료가 서로 어긋나는 쟁점(대계단 높이, 회경전문 칸수, 중정 포장, 공포 형식 등)은
  연구 노트 6.1절에 채택안과 함께 표로 남겼습니다.

좌표는 회경전 중심축에 맞춘 PLAN 좌표계(미터, x=동, z=남, y=위, 원점=회경전 기단 중심)입니다. 자세한 약속은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

**점검**: `node tools/shoot.mjs index.html --size 1280x800 --steps '[{"eval":"__app.tour.go(4, true)","wait":800,"shot":"t4.png"}]'`
처럼 테스트 API(`window.__app`: `tour.go`, `setTime`, `setRuins`, `setWalk`, `select`, `setAlt`, `lookAt`, `info()`, `prebuild()`)로 장면을 바꿔 가며 찍을 수 있고,
콘솔 오류가 하나라도 있으면 실패합니다.

## 성능

안내 여행 12곳과 첫 화면에서 잰 값입니다(한 프레임의 본 그리기 기준, 헤드리스 Chromium). 그림자 맵은 빛이나 보는 곳이 바뀔 때만 따로 다시 그립니다.

| 화질 | 그리기 호출 | 삼각형 | 그림자 맵을 다시 그리는 프레임에 더해지는 양 |
|---|---|---|---|
| 높음 (데스크톱, 1280×800) | 약 115–245회 | 약 53만–92만 개 (그중 숲 약 24만–42만) | 90–340회, 32만–69만 개 |
| 보통 (휴대폰 기본, 390×844) | 약 90–190회 | 약 44만–65만 개 (숲 약 14만) | 80–270회, 21만–44만 개 |
| 낮음 (그림자 없음, 1280×800) | 약 110–240회 | 약 45만–78만 개 (숲 약 8만) | — |

전각은 거리에 따라 세 단계(높음·보통·낮음)로 바뀌고, 경계에서 깜박이지 않게 10 % 여유를 둡니다. 가장 자세한 단계는 처음부터 짓지 않아
불러오기가 빠른 대신, 불러온 뒤 **장면이 가만한 틈마다 한 채씩** 안내 여행 지점 둘레(지점 카메라에서 보통 단계 거리의 1.5배 안)와
1·2등급 전각의 가장 자세한 단계를 미리 짓습니다(`requestIdleCallback`, 없으면 `setTimeout`). 누르기·끌기·휠·키 입력이나
비행·걷기 조작이 있으면 쉬었다가 1.2 초 조용하면 이어 가고, 복원 선택지로 다시 지은 전각도 다시 미리 짓습니다(데스크톱 44채 · 지오메트리 약 36 MB,
휴대폰은 LOD 거리가 짧아 39채 · 약 33 MB). 미리 짓지 못한 전각은 카메라가 다가올 때 짓되, 한 프레임에 30 ms 를 넘기면 나머지는 다음 프레임으로 미룹니다(그동안은 보통 단계).
그래서 안내 여행 6번째 지점(회경전 뜰)으로 순간 이동할 때 한 프레임에 짓던 시간이 **8채 265–605 ms → 0 ms**(미리 짓기가 끝난 뒤),
불러오자마자 곧바로 가도 **2채 약 90 ms** 로 줄었습니다(데스크톱; 휴대폰 흉내는 3채 138 ms → 0 ms).

가장 먼 단계는 무늬 텍스처 대신 평균색을 칠한 두 메시(기단·몸체)이고, 그 기단과 서까래 마구리·금동 장식·금박·편액은 그림자를 드리우지 않습니다
(재질의 `noCastShadow` 표시 — 합쳐 그리는 계단 난간의 금동 장식도). 계단·다리·담장은 재질별로, 회랑은 일곽(대지)별·재질별로 합쳐 그려 화면 밖 일곽은 건너뜁니다.
궁성·황성·나성 성벽은 재질별로 하나씩 합치면 경계 구 반지름이 3.4 km 라 늘 화면·그림자 상자 안으로 셈이 되므로, 궁궐에서 1.3 km 안(궁성·황성)은
한 덩이로, 그 밖(나성)은 1.4 km 칸(2.8 km 밖은 2.8 km 칸)으로 나눠 합칩니다(메시 6 → 20개). 한 화면의 성벽 삼각형이 5.5만 → 2.7만–4.1만,
그림자 패스에서는 5.5만 → 2.3만–2.7만 개로 줄고, 그리기 호출은 본 패스에서 2–6회, 그림자 패스에서 0–2회 늘 뿐입니다.
휴대폰·낮은 화질에서는 서까래·막새 원판을 뺀 가벼운 회랑을 씁니다. 숲은 인스턴싱하되 타일(나무 900 m, 덤불·바위 3 km)로 나눠 화면 밖 타일을
건너뛰고, 480 m 밖 나무는 삼각형 20개 남짓한 간단한 모양으로 그립니다. 움직이지 않는 물체는 행렬을 한 번만 계산하고,
누르기·마우스 올림 판정은 큰 메시를 삼각형 묶음 상자로 먼저 걸러 몇 ms 안에 끝납니다.
장면은 무언가 바뀔 때만 다시 그리므로, 가만히 보고 있을 때는 GPU 를 거의 쓰지 않습니다.
